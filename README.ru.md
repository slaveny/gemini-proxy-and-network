### 🌹 Fascinating Rose : Адаптивный веб-интерфейс и ИИ-прокси для Gemini API в Docker

![Fascinating Rose](html/logo.png)

**Fascinating Rose** — это легковесный, полностью адаптированный под мобильные устройства веб-интерфейс чата со встроенным Python-прокси для работы с Google Gemini API (Free Tier). Проект спроектирован по микросервисной архитектуре, полностью изолирован внутри Docker-сети и защищен сквозным SSL-шифрованием силами Nginx.

Является донастройкой "под себя" ala форком проекта автора `rainy351/gemini_proxy`.

В папке проекта имеются актуальные на данный момент `allmodells.txt`.
Отличается наличием Web-интерфейса и выбором модели;

#### 🔥 Ключевые особенности

* 📱 **Адаптивный дизайн (100dvh):** Интерфейс построен на Flexbox. Поле ввода жестко фиксируется над клавиатурой на любых смартфонах и не улетает вниз при вводе текста.
* 🛡️ **Безопасность API-ключей:** Секретный токен вводится в браузере, не сохраняется меж сессиями.
* 🧠 **Поддержка современных моделей:** Из коробки доступен выбор между `Gemini 3.5 Flash`, `Gemini 3.7 Flash`, `Gemini 3.1 Pro Preview`, а также специализированными TTS и Transcribe моделями.
* 📦 **Развертывание одной командой:** Весь проект со статикой, Python-сервером и SSL-шлюзом Nginx поднимается через один манифест Docker Compose.
* 🎨 **Эстетичный визуал:** Полупрозрачные стеклянные плашки сообщений чата плавно скроллятся поверх зафиксированного неонового фона кибер-розы с эффектом матового стекла (`backdrop-filter: blur`).

---

#### 🏗️ Архитектура проекта

Система разделена на три независимых слоя ответственности:

1. **Фронтенд (`html/`)**: Статические файлы `index.html` и `chat.js`, которые мгновенно отдаются веб-сервером Nginx напрямую с диска, минуя Python-код.
2. **Бэкенд-прокси (`app.py`)**: Легковесное Flask-приложение на базе Gunicorn. Оно нормализует входящие URL-пути, вырезает дублирующиеся префиксы версий API (`/v1beta/`) и проксирует поток ответов от серверов Google.
3. **Шлюз безопасности (`Nginx`)**: Фронт-контроллер, принимающий защищенный HTTPS-трафик на порту 443 и перенаправляющий его во внутреннюю сеть Docker на порт закрытого Flask-приложения.

#### 🛠️ Развертывание и запуск

##### 1. Подготовка папок и файлов
Убедитесь, что структура проекта на сервере выглядит следующим образом:
```text
├── docker-compose.yml
├── Dockerfile
├── app.py
├── .env
├── html/
│   ├── index.html
│   ├── chat.js
│   └── logo.png        # Ваша фоновая картинка кибер-розы
└── nginx_conf/
    └── default.conf
```

##### 2. Создание файла окружения `.env`
Создайте файл `.env` в корневом каталоге и укажите целевой внутренний порт для приложения, он не будет торчать наружу, а используется для связи с nginx:
```env
PORT=25200
```

##### 3. Запуск системы
Для сборки образов без использования старого кэша и запуска всей инфраструктуры в фоновом режиме выполните в терминале сервера одну команду:

```bash
docker-compose up -d --build
```

Проект запустится и станет доступен по защищенному протоколу HTTPS.

#### 📈 Управление и логирование

* **Просмотр логов бэкенда в реальном времени:**
  ```bash
  docker logs -f gemini_proxy
  ```
* **Просмотр логов веб-сервера Nginx:**
  ```bash
  docker logs -f gemini-nginx
  ```
* **Полная остановка и удаление контейнеров проекта:**
  ```bash
  docker-compose down
  ```
